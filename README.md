## ✨ Features

* **Modern Design:** Dark floating glassmorphism navigation header with gradient brand accents.
* **Responsive Layout:** Optimized for mobile phones, tablets, and desktop computers.
* **Interactive Navigation:** Smooth scrolling links, sticky header with scroll shadow, and animated mobile drawer menu.
* **Sections Included:**
  * **Hero/About:** Quick introduction, CV links, and direct social profile badges.
  * **Skills:** Highlights experience in Frontend Development, Video Editing, Audio Editing, and Content Creation.
  * **Education:** Interactive timeline displaying ongoing BCA (Data Science & AI) and high school background.
  * **Projects:** Showcase of recent social media/editing projects with quick action buttons.
  * **Contact:** Functional input card for user emails.
* **Direct Social Media Integration:** Icon links pointing to GitHub, LinkedIn, Personal Instagram, Coding Instagram, and YouTube.
